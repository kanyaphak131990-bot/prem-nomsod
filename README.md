# 🥛 เปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ Landing Page ของร้าน **"เปรม นมสด"** ร้านนมสดแท้ ขนมปังปิ้งเตาหอม ปังเย็นภูเขาไฟ และของทานเล่นยามค่ำคืน

---

## 🌟 จุดเด่นของเว็บไซต์
- **ดีไซน์ทันสมัย & บรรยากาศอบอุ่น:** ออกแบบด้วยโทนสีฟ้า-ขาว และแสงไฟสีวอร์ม สไตล์ร้านนมยามค่ำคืน
- **เมนูแนะนำ & ระบบกรอง:** แยกหมวดหมู่นมสด, ขนมปังปิ้ง/ปังเย็น และของทานเล่น (นักเก็ต, เกี๊ยวทอด, เฟรนช์ฟรายส์)
- **Authentic Chalkboard:** ป้ายกระดานดำจำลองราคาและเวลาเปิด-ปิดร้าน (17:00 - 22:00 น.) ตามรูปถ่ายจริง
- **แกลเลอรีรูปภาพ & Lightbox:** คลิกชมภาพอาหารและบรรยากาศจริงขนาดใหญ่ได้
- **เชื่อมต่อ Facebook เพจร้าน:** มีปุ่มลิงก์ตรงไปยังเพจเฟซบุ๊กทั้งในเมนู, หน้าแรก, ข้อมูลติดต่อ และปุ่มลอย (Floating Sticky Button)
- **Fully Responsive:** รองรับการแสดงผลทุกขนาดหน้าจอ ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

---

## 🛠️ เทคโนโลยีที่ใช้
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (CDN)**
- **Font Awesome 6 (Icons)**
- **Google Fonts:** Kanit, Prompt, Mali

---

## 📂 โครงสร้างโฟลเดอร์
```text
ร้านนม/
├── index.html          # หน้าหลักของเว็บไซต์
├── logo.png            # โลโก้ทางการของร้านเปรม นมสด
├── README.md           # คำอธิบายโปรเจกต์
├── บรรยากาศในร้าน/     # รูปถ่ายบรรยากาศร้านยามค่ำคืน
└── เมนูร้าน/            # รูปถ่ายเมนูเครื่องดื่ม ขนมปัง และของทอด
```

---

## 🚀 วิธีเปิดใช้งาน
ดับเบิลคลิกไฟล์ `index.html` หรือเปิดผ่านเว็บบราวเซอร์ใดก็ได้ (Google Chrome, Microsoft Edge ฯลฯ)
